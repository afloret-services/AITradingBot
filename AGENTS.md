# AITradingBot

An automated trading bot for futures (NQ, MNQ, ES, MES) and forex, trading ICT (Inner Circle Trader) setups through Interactive Brokers.

Issues and specs live in this repo's GitHub Issues. See `docs/agents/issue-tracker.md`.

The five default triage labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.
